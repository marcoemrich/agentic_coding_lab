## Story

One table per kata, rows labelled by varying RQ factors and columns for declared outcomes, n and cost. The React result table supports sorting. Implemented in `site/src/result-table.ts` and `site/src/ResultTable.tsx`; tests in `site/src/result-table.spec.ts` and `site/src/ResultTable.spec.tsx`.
