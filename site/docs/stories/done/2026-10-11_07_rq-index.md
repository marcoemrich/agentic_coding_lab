# RQ index

Status: done
Source: [results-site decisions](../../open-questions.md#other-pages); mapped with the user on 2026-10-15.

## Story

The site's start page lists every main RQ grouped by harness subtree — Claude Code, pi, OpenCode, Cursor CLI, Across harnesses — and ordered by chapter label. Each entry shows the question, linked to the RQ page, the RQ id beneath it and one line of facts: coverage, ok runs and their span (`10/12 cells, 58 runs, 2026-08-03 → 2026-08-17`). An RQ without runs is listed as “no data yet” and gets no page; one with runs but no ok run reads “no ok runs yet” and keeps its page. Every page carries a top bar with the site name, a “Questions” link and the stamp `Data as of <build time> UTC, <N> runs`. The RQ page header follows the index: a span always names both dates, and there is no singular (`1 runs`). There is no `closed` badge; dropping the `closed:` field altogether is a to-do in `todos_and_ideas/1-IN/`.

## Built

Implemented with the `exact-coding` skill; 20 new tests — 15 in `src/RqIndex.spec.tsx` (“RQ index”, “RQ pages”), 5 in `src/TopBar.spec.tsx` — and two replaced in `src/RqHeader.spec.tsx` for the header's span and singular, 148 Vitest tests in all. Grouping and order live in `rq-index.ts`, the markup in `RqIndex.tsx`, as with `result-table.ts` and `ResultTable.tsx`; which RQ gets a page is `hasPage()` in `rq-pages.ts`, shared by the index link and the Astro route. The run facts (`okRunIds`, `okRunCount`, `coveredCells`, `okRunsAndSpan`, `hasAnyRun`) are one implementation in `rq-runs-summary.ts`, used by the header, the index and the stamp. Readings adopted: the chapter label is compared numerically part by part (4.9 before 4.10) and never shown; equal labels have no defined order; the stamp counts distinct ok run ids across all main RQs, with an `en-US` thousands separator, and takes the Astro build time in UTC; “Questions” is marked current on the index only; the index intro drops the prototype's sentence about AI-generated findings until findings are shown. Deviations: the span change also touched two header tests that happened to expect a single day; leaving out empty groups was forced earlier than listed, by the grouping test. “no data yet” and “no ok runs yet” are reachable only in tests today — all 46 main RQs have ok runs.
